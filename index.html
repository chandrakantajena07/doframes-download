एक रिकॉर्डिंग। दो नज़रिये। · Record once, create twice.

Records a 9:16 vertical and a 16:9 horizontal video at the same time, with one shared microphone track and live filters. Works offline. No account. No internet permission.

Download APK

Android 8.0+ · about 1.6 MB · release notes
Install
  • Open the downloaded file on your phone.
  • If asked, allow "Install unknown apps" for your browser, once.
  • Open दोFRAMES and allow camera and microphone.
Updates install over the old version because every release uses the same signing key.
Good to know
  • Uses one camera and crops it into both outputs.
  • 4K30 and 1080p60 show up only if your phone supports them.
  • Videos save to Movies/DOFRAMES.

Privacy: nothing leaves your device. No analytics, no tracking.
